# Framer Content History

Framer remains authoritative for the presentation and live publication of
`planet2x.com`. This directory keeps Git-backed historical memory for important
written copy.

## Workflow

For a meaningful copy change:

1. Snapshot the current published copy.
2. Make the approved edit in Framer.
3. Verify the draft and obtain human approval.
4. Publish through Framer.
5. Record the new published copy as the current snapshot.

Snapshots are not required for trivial typo, punctuation, or capitalization
corrections. When such a publication sits between meaningful versions, record
its provenance in the relevant history without creating a separate prose
snapshot.

This is copy history, not a Framer project backup. Do not archive generated
Framer code, layout, components, or visual assets here merely for backup.
